# 3-Minute Demo Script

**0:00–0:20 — Product intro**
- “This is TradeSim Pro, a virtual stock trading terminal built for the assignment. It uses a controlled synthetic dataset, so no real money or real trades are involved.”

**0:20–0:55 — Market exploration**
- Show the 10-stock watchlist.
- Search a symbol.
- Select the instrument.
- Change date and exact 30-minute time.
- Point out price, change, open/high/low and the intraday chart.

**0:55–1:15 — Replay**
- Press Replay.
- Show the timestamp moving through the session and the selected price updating.

**1:15–1:55 — BUY**
- Enter a quantity.
- Show estimated order value.
- Execute BUY.
- Show cash decreasing and a new portfolio position.

**1:55–2:25 — Portfolio analytics**
- Point out invested cost, market value, unrealized P/L and return.
- Explain that the backend uses weighted-average cost.

**2:25–2:45 — SELL + audit trail**
- Sell part of the holding.
- Show cash/position update.
- Scroll to transaction history and show BUY/SELL records.

**2:45–3:00 — Reset + close**
- Click Reset Demo.
- “The predefined virtual account is restored. The project is fully local, uses CSV-backed market data, and has no real-money functionality.”
